# v0.2.0 클라우드 마일스톤 셋업 가이드

이 문서는 **마님 Google 계정**으로 Firebase 프로젝트를 만들고, BudgetBook을 클라우드
공유 가계부로 전환하기 위한 단계별 안내입니다.

> **계정 정책** — 실제 주 사용자·관리자가 마님이므로 Firebase 프로젝트 owner는
> 마님 계정으로 둡니다. 본인(남편)은 "허용된 가족 구성원" 자격으로 앱에 로그인하여
> 동일한 데이터에 접근합니다. 청구 알림·보안 알림은 마님에게 직접 전달됩니다.

## Phase 1 — Firebase Console 작업 (마님이 직접)

### 0. 사전 준비

- 마님 Google 계정 (gmail) — 일상에서 쓰시는 그 계정
- PC 또는 폰 브라우저 (Chrome/Safari 무관)
- 약 30분의 여유 시간

### 1. Firebase 프로젝트 생성

1. 브라우저에서 https://console.firebase.google.com 접속
2. **마님 Google 계정으로 로그인** (이미 로그인된 다른 계정이 있다면 우상단에서 전환)
3. 「프로젝트 만들기」 클릭
4. 프로젝트 이름 입력 — 권장: `budgetbook-family` 또는 `our-budget-book`
   - ⚠️ 이 이름이 무료 도메인 일부가 됨 → `https://budgetbook-family.web.app`
   - 영문 소문자 + 숫자 + 하이픈만 사용 가능
   - 너무 평범한 이름은 이미 누가 썼을 수 있어요 (자동으로 뒤에 숫자 붙음)
5. Google Analytics: **사용 안함** 선택 (가계부에 불필요, 무료 한도 절약)
6. 「프로젝트 만들기」 → 1분 대기 → 「계속」

### 2. Authentication 활성화 + Google 로그인 켜기

1. 좌측 메뉴 「Build → Authentication」
2. 「시작하기」 클릭
3. 「Sign-in method」 탭
4. 「Google」 행 클릭 → 「사용 설정」 토글 ON
5. **프로젝트 지원 이메일**: 마님 이메일 선택 (기본값 그대로)
6. 「저장」

### 3. 가족 구성원 사전 등록 (선택사항)

여기서 마님 + 본인(남편) Google 계정을 미리 등록해두면 첫 로그인 시 자동으로 통과됩니다.
**미등록 상태로 두고 로그인할 때 자동 등록되도록 하는 것도 OK** — Firestore 보안 규칙에서
허용된 이메일만 데이터 접근하도록 막을 거니까요.

만약 사전 등록을 원하면:
1. Authentication → 「Users」 탭 → 「사용자 추가」
2. 마님 이메일 + 임시 비밀번호 (Google 로그인이라 안 써도 무방)
3. 본인(남편) 이메일도 동일하게 추가

> **권장**: 이 단계는 건너뛰고, 다음 단계 모두 끝낸 다음에 두 사람 모두 한 번씩
> Google 로그인을 시도하면 자동으로 User 목록에 잡힙니다. 그게 더 깔끔해요.

### 4. Firestore Database 활성화

1. 좌측 메뉴 「Build → Firestore Database」
2. 「데이터베이스 만들기」 클릭
3. **위치**: `asia-northeast3 (서울)` 선택
   - ⚠️ 한 번 정하면 변경 불가. 한국 사용자 지연 최소화를 위해 서울 필수
4. **시작 모드**: 「테스트 모드로 시작」 선택
   - ⚠️ 30일 후 자동 잠금됨 — Phase 2에서 Claude가 보안 규칙 작성 후 적용할 거예요
5. 「사용 설정」 클릭

### 5. Hosting 활성화

1. 좌측 메뉴 「Build → Hosting」
2. 「시작하기」 클릭
3. 안내 화면 그냥 「다음 → 다음 → 콘솔로 이동」
   - CLI 설치 안내는 무시. Claude가 배포 자동화 설정할 거예요.

### 6. Web 앱 등록 + 설정 키 받기

1. 좌측 톱니바퀴(⚙️) → 「프로젝트 설정」 클릭
2. 「내 앱」 섹션에서 「`</>` (웹)」 아이콘 클릭
3. 앱 닉네임: `BudgetBook Web` (아무거나 OK)
4. **「Firebase Hosting 설정도 함께」 체크박스 ON** ← 중요
5. 「앱 등록」 클릭
6. 다음 화면에서 `firebaseConfig` 객체가 표시됨 — **그대로 복사**:
   ```js
   const firebaseConfig = {
     apiKey: "AIza...",
     authDomain: "budgetbook-family.firebaseapp.com",
     projectId: "budgetbook-family",
     storageBucket: "budgetbook-family.appspot.com",
     messagingSenderId: "123456789",
     appId: "1:123456789:web:abc..."
   };
   ```
7. 메모장에 저장 → 이 채팅에 붙여넣기

### 7. 인증된 도메인 확인

1. Authentication → 「Settings」 탭 → 「Authorized domains」
2. 자동으로 `localhost`, `<프로젝트>.firebaseapp.com`, `<프로젝트>.web.app` 들어가 있을 것
3. 추가 등록 불필요 (커스텀 도메인 안 씀)

### 8. (선택) 본인 계정도 프로젝트 관리자로 추가

만약 본인(남편)도 Firebase Console에 직접 접근해서 상태를 보고 싶다면:
1. ⚙️ → 「사용자 및 권한」
2. 「구성원 추가」 → 본인 Google 계정 이메일 입력
3. 역할: **Editor** 선택 (Owner는 마님만)

> 이거 안 해도 앱은 정상 동작합니다. 본인은 어차피 Console 안 봐도 되고, 마님이 IAM
> 관리자니까. 필요할 때만 추가하세요.

## Phase 2 — 코드 통합 (Claude가 진행)

마님 firebaseConfig 받으면 Claude가:

1. ✅ `firebase` npm 패키지 설치 (`app/package.json`) — Phase 1 중 미리 완료
2. ✅ `app/.env.example` 작성 — Phase 1 중 미리 완료
3. ✅ `app/src/renderer/src/lib/firebase.ts` — Firebase 초기화 모듈 (스켈레톤)
4. ✅ `AuthContext` — React Context로 로그인 상태 관리 (스켈레톤)
5. ✅ `LoginView` — Google 버튼 1개짜리 단순 화면 (스켈레톤)
6. ✅ `App.tsx` — 로그인 게이트 (스켈레톤)
7. `firestore.rules` — **가족 구성원 화이트리스트** 기반 접근 제어:
   ```
   match /budgets/{doc} {
     allow read, write: if request.auth.token.email in [
       "마님이메일@gmail.com",
       "본인이메일@gmail.com"
     ];
   }
   ```
   (실제 이메일은 채팅에서 확정 후 적용)
8. `.env` 파일에 firebaseConfig 값 주입 (git ignore)

5. 가족 공유 모델 — 모든 문서는 `familyId` 필드를 가지고, 마님 + 본인 두 UID 모두 같은
   `familyId` 그룹으로 묶임

## 자주 묻는 질문 (FAQ)

### Q. 본인(남편)이 마님 계정으로 대리 작업해도 되나요?

가능합니다. 마님 노트북/폰에서 마님 계정으로 로그인해서 본인이 직접 클릭해도 결과
동일. 다만 2FA(2단계 인증)가 걸려있으면 마님 폰 인증 필요할 수 있어요.

### Q. 나중에 owner를 본인으로 옮길 수 있나요?

가능합니다. ⚙️ → 「사용자 및 권한」에서 본인 계정을 Owner로 추가하고 마님 Owner를
Editor로 강등하면 됨. 단 청구 계정(연결된 카드/한도)은 별도라 무료 티어 동안은 의미
없음.

### Q. 마님 Google 계정이 잠기면 어떻게 되나요?

- 데이터: 안전 (Firestore에 그대로 남음)
- 접근: 임시 차단됨. Google 계정 복구 후 정상화
- 백업: Phase 5의 일회성 마이그레이션이 끝나도 **로컬 SQLite는 그대로 둘 거**라 본인 PC에서 v0.1.15 실행 가능

### Q. 마님 + 본인 외 누군가 (예: 자녀) 추가하고 싶으면?

Phase 2의 Firestore Rules에 그 사람 Google 이메일을 추가하면 끝. 코드 한 줄 수정.
